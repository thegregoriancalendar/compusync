Screen layout

Each physical monitor is shown inside its computer group. Drag any monitor to move that computer; drag empty space to pan, and scroll to zoom. Positions within each group follow the operating system’s display settings.

Connection help

Allow CompuSync through the firewall on your private network. Guest Wi-Fi may block laptop-to-laptop connections. If pairing fails, check the code or generate a new one. You can also enter the address in the pairing section’s Connection help. A sleeping or fully quit app cannot receive a window; the connection returns automatically when it is available again.
